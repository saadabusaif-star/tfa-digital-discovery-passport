# ICT Display Resource Notes

## Source 1: `za-kps-1730717288-ict-display-poster_ver_1.pdf`

- Single-page ICT poster.
- Main visual theme: large globe/network icon with the title **ICT**.
- Supporting imagery: two students using desktop computers on opposite sides.

## Source 2: `t-i-098-computer-keyboard-shortcuts-display-posters_ver_1.pdf` (pages reviewed: 1–3)

- Poster format uses one shortcut per page with a simple word label, key combination, and icon.
- Page 1: **Open** → `Ctrl + O` with folder icon.
- Page 2: **Close** → `Ctrl + W` with close/X icon.
- Page 3: **New Document** → `Ctrl + N` with blank-page icon.
- Overall cues useful for the website: quick-recognition matching, keyboard literacy, simple symbol-to-action learning, short classroom-safe prompt style.

## Initial activity direction

- Best-fit integration is a new mini activity focused on **ICT skills recognition** rather than a passive poster gallery.
- Strong candidate format: students identify shortcut meanings, digital symbols, or computing actions using a fast three-step challenge that matches the rest of the simplified Welcome Day flow.

## Source 3: `t-m-1678-computing-display-banner-_ver_4.pdf`

The single-page banner presents the title **Computing** with diverse students working at computers, a laptop, a VR headset, and desk workstations. Its bright blue circuit backdrop and inclusive classroom scene reinforce the same school-computing setting as the ICT poster. The new activity should therefore use the student-facing title **Computing Quick Skills**, drawing on the supplied poster concepts through a short, visual, three-question challenge about common shortcuts and basic computing symbols.
