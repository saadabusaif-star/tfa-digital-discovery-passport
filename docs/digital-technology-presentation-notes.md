# Digital Technology Presentation Notes

## Supplied presentation

The supplied **Digital Technology or Not?** presentation contains ten slides. Its core definition is that digital technology is a tool used to **get, send, and save information**. The student interactions ask learners to identify which objects are digital technology, identify objects that are not digital technology, and sort mixed objects into **Technology** and **Not technology** groups.

## Visual direction retained in the website

The presentation uses a bright sky-blue classroom scene, friendly illustrated children, simple rounded white prompt panels, black hand-drawn outlines, and playful object recognition. The new website activity will carry that friendly, approachable classification style while retaining the existing TFA navy, lime, and UAE-focused event identity. A supplied technology-object illustration will be displayed in the activity panel; the original PowerPoint file will remain outside client assets.

## Question-bank use

The presentation directly informs an age-appropriate **Digital Technology or Not?** bonus activity. Its question bank will include object classification, information sharing, safe use, and digital-versus-non-digital sorting concepts, with simpler wording for Grades 6–7 and progressively more analytical prompts for Grades 8–9 and 10–12.
